Blockchain-Secured Attendance System

Cryptographic Integrity & Fraud Prevention Infrastructure

A tamper-evident, cryptographic attendance verification infrastructure engineered to prevent proxy signing and attendance fraud through SHA-256 hash chaining, device fingerprinting, and geofencing.

Cryptographic Controls

Core System Architecture

SHA-256 Hash Chaining

Each recorded entry contains a cryptographic SHA-256 hash calculated from the previous entry. Tampering with any historical record invalidates all subsequent hashes.

Device Fingerprinting

Extracts unique hardware parameters to ensure student check-ins are restricted to registered hardware, preventing multi-account proxy signing.

Geofence GPS Validation

Validates student geolocation coordinates against defined lecture hall boundaries to guarantee physical presence during attendance logging.
