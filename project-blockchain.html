Blockchain-Secured Attendance

Tamper-Evident Cryptographic Verification System

A tamper-evident, cryptographic attendance verification infrastructure engineered to prevent proxy signing and attendance fraud. Integrates SHA-256 hash chaining, device fingerprinting, geofenced GPS verification, and Web3 anchoring.

View GitHub Repo Back to Projects
Integrity Architecture

Core Security Features

1

SHA-256 Hash Chain

Each attendance record cryptographically references the SHA-256 hash of the previous record, creating an immutable chain of evidence.

2

Device Fingerprinting

Captures unique hardware fingerprints from the accessing device to verify physical presence and prevent proxy signing.

3

Geofenced GPS Verification

Validates that the student's location falls within pre-defined geographic boundaries (e.g., LAUTECH campus) before accepting attendance.

4

Web3 Immutable Anchoring

Records anchored to Web3 infrastructure ensure that attendance data cannot be modified retroactively without breaking the chain.

5

AI-Assisted Administration

Intelligent administrative dashboard for monitoring attendance patterns, detecting anomalies, and generating verification reports.
