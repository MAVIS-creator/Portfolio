FUTURE DIRECTIONS & RESEARCH

CURRENTLY EXPLORING

AI × GAMING × SOFTWARE × CYBERSECURITY

Technology is most exciting at the intersections: where two or three distinct disciplines collide to create something completely new.

Right now, my research and development focus centers around four core convergence pillars:

01 /

Multi-Model AI Orchestration

Combining specialized AI models (code generation, security auditing, multi-modal vision) into collaborative agentic workflows that solve complex problems.

02 /

Real-Time Gaming Systems

Bringing game engine state machines, physics-based simulations, and low-latency interactive loops into non-gaming software architecture.

03 /

Next-Gen Software Architecture

Building software that adapts dynamically to user behavior, self-corrects runtime errors, and maintains high performance under load.

04 /

Proactive Security Engineering

Designing systems that embed cryptographic integrity verification, geofenced access tokens, and automated threat isolation directly into the core code.

By keeping these domains closely connected, every experiment becomes a building block for something bigger. Keeping focus makes the software far more robust.
